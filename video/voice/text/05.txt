Every change goes through the same line. A structural merge that understands code. Typecheck and tests. Then a model's review, labelled as an opinion, because tests are evidence and a review is not. Then Clef gives a calibrated probability: ninety-four percent land, so it lands. When it isn't sure, a person decides. And when two agents edit the same line, a model can merge them in the queue, and the tests still decide. Security is evidence too: turn it on, and every batch also runs secret, dependency and code scanners, and a new finding fails the change, just like a failing test.
