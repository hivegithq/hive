Here's a real run: seven goals, three different models, all started at once, each in its own fork. As they declare intent, Hive compares them. Two are about to change the same function, and that's caught before any code exists. A third changes what a function returns while another edits code that calls it. A line-based merge would accept that and ship a bug. Hive's code graph sees it, and Clef, the decision model, tells the agent to narrow its scope. Disjoint changes land first. And one change that couples to code trunk changed meanwhile is held for a person to confirm.
